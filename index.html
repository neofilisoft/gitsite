README.md

Blender

Blender is the free and open source 3D creation suite. It supports the entirety of the 3D pipeline — modeling, rigging, animation, simulation, rendering, compositing, motion tracking and video editing.

Getting Started

Official releases are available on blender.org/download. Nightly builds are available on builder.blender.org.

Build Instructions

For detailed build instructions see the developer documentation.

# Clone the repository git clone https://projects.blender.org/blender/blender.git cd blender # Initialize submodules make update # Build make

Contributing

Contributions are welcome! Please read the Contributor Documentation before submitting patches. All development happens on the official Blender Projects server.
